# たからさがし ちず

家の中で「たからさがし」をする、子ども向けのアプリです。
おうちのひとがヒントを作り、子どもはヒントを頼りに家の中を探し回ります。

## あそびかた

1. **おうちのひと**：ホーム画面下の「おうちのひと」を1.5秒ながおしして、ぼうけんを作ります。
   - しまごとに「ヒント」と「あいことば（カードの絵）」を決めます。
   - 「あいことばカードをいんさつ」で印刷し、ヒントの場所にカードを置きます（手書きでもOK）。
   - 最後に出る「おたからの場所」に、本物のおたから（おかしなど）を隠します。
2. **こども**：「ぼうけんにでる！」を押し、ヒントを読んで（または聞いて）場所を探します。
3. カードを見つけたら「カードをみつけた！」を押し、カードと同じ絵を選びます。
4. 全部のしまを回ると、おたからの場所が表示されます。

## しくみのメモ

- `index.html` 1つだけで動きます。サーバーやAIは使っていないので、お金はかかりません。
- 作ったぼうけんは、そのiPadのブラウザの中にだけ保存されます（他の端末には共有されません）。
- iPadのSafariで開き、共有ボタン →「ホーム画面に追加」で、アプリのように開けます。
